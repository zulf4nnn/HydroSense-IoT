# Smart Plant - Sistem Monitoring & Irigasi Otomatis Berbasis IoT

Dokumentasi pengembangan sistem IoT berbasis ESP32 untuk solusi 
penyiraman tanaman otomatis berbasis data sensor kelembapan tanah real-time.

---

## Deskripsi Project

Project ini dikembangkan sebagai bagian dari tugas mata kuliah IoT 
di STMIK Tazkia. Fokus utama adalah pada otomatisasi irigasi tanaman 
berdasarkan monitoring kelembapan tanah secara real-time, dengan tujuan 
mengurangi kelalaian penyiraman manual dan pemborosan sumber daya air.

### Fitur Utama

- Monitoring kondisi tanah dan lingkungan via dashboard Blynk (mobile/web)
- Otomatisasi pompa air berdasarkan threshold kelembapan tanah
- Monitoring suhu dan kelembapan udara menggunakan sensor DHT11
- Sistem daya mandiri berbasis baterai 18650 (portabel tanpa kabel listrik)
- Arsitektur modular yang dapat dikembangkan untuk skala lebih besar
